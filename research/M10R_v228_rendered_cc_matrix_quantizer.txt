=== SetWhiteXY object layout from direct stores/calls ===
object base in caller = SP+0x68
+0x00/+0x08 : WhiteXY doubles (direct SetWhiteXY stores)
+0x10..+0x20: CameraWhite vector (direct SetWhiteXY stores)
+0x28..+0x68: 3x3 matrix used by caller at SP+0x90
+0x70..+0xB0: second 3x3 matrix populated by SetWhiteXY matrix operations
Public DNG ColorSpec names these positions CameraToPCS and PCStoCamera; firmware dataflow must be used to confirm semantics before freezing the labels.

=== DECISION ===
Freeze CC0/CC1 formula only if the builder input pointers can be tied to the above two matrices without relying on API-name analogy.
Freeze quantization only from explicit coefficient scaling/rounding/scale-code instructions in 0x400038B0.
