# M10rCamera

The current Android implementation is the
[COLOURCACHE3H checkpoint](checkpoints/colourcache3h/README.md), version
**1.39-m10r-colourcache3h-test**. Its pinned source overlay assembles the same
PhotonCamera-based app as the delivered test build.

See the checkpoint for build instructions, exact source/native hashes, validation
results, PHOTO/MOTION support and remaining phone checks. Earlier investigation
documents and tools remain under `research/`, `tests/` and `tools/`; historical
development branches are retained.
